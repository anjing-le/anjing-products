# 下方功能牌的共同纸面

参照用户认可的 EnglishX 白纸卡片，由内置 image_gen 以 `assets/english-4.webp` 为参考生成不含图案的暖白细纤维纸纹。原图及完整提示词保留在 `docs/artwork/shared/`，网页加载 `assets/card-paper-v1.webp`。

所有下方功能牌和个人文字牌使用同一纸面、暖灰切边、两层薄纸边与轻投影。纸纹整面覆盖，不重复铺贴以避免接缝；边缘处理由 CSS 负责，不将网页背景或外部卡牌投影烘焙进素材。

macos-x 与 cs-tool-x 的说明插画保留完整画幅及原有文字，增加少量纸面留边，使用轻微提亮、正片叠底和边缘淡化，让原图白底与共同纸面衔接。EnglishX 保留原有剪纸主体与内置的细小浮雕阴影，通过同一纸面及实体牌边与其他卡片衔接。

本轮统一的是卡片纸材与图片的承载关系。原有说明插画仍是印刷／蜡笔语言，不声称 CSS 已将其内部物体重建为三维剪纸。功能文字未重新生图，继续保留点击阅读原始大图。
